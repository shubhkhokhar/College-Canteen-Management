# College Canteen Management System

## Overview

The College Canteen Management System is a simple Python-based
command-line project. It allows a student to enter their details,
view the canteen menu, select a food item, enter the quantity,
and calculate the total bill.

## Features

- Enter student name and roll number
- Display food menu
- Select food item
- Enter quantity
- Calculate total bill
- Display final bill

## Technology Used

- Python
- Command Line Interface

## Requirements

- Python 3.x
- VS Code or any Python-supported editor

## How to Run

1. Download or clone the project repository.
2. Open the project folder in VS Code or terminal.
3. Open the Python file.
4. Run the following command:

python main.py

5. Enter the student details.
6. Select a food item and enter the quantity.
7. The final bill will be displayed.

## Testing

The program was tested using different food items and quantities.
The total bill was checked using the selected item's price and
quantity.
